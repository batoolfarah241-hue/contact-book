# Contact Book Manager

A simple command-line contact manager written in Python. Contacts are saved
to a local `contacts.json` file, so they persist between runs.

## Features
- Add a new contact (name, phone, email)
- View all saved contacts
- Search contacts by name
- Delete a contact
- Data is stored in a JSON file (no database required)

## Concepts practiced
- Functions and program structure
- Dictionaries and lists
- Reading and writing JSON files
- Basic exception handling
- Menu-driven `while` loops

## How to run
```bash
python contact_book.py
```

## Example
```
==== Contact Book ====
1. Add contact
2. View all contacts
3. Search contact
4. Delete contact
5. Exit
Choose an option (1-5): 1
Name: Ali Raza
Phone: 0300-1234567
Email: ali@example.com
Contact 'Ali Raza' added.
```
